Overview

The Redux Counter Application is a simple web-based project built using React.js and Redux. It demonstrates the core principles of Redux for managing global application state in a predictable and scalable manner. The application allows users to increment, decrement, and reset a counter value through centralized state management.

Features

-Increment the counter value

-Decrement the counter value

-Reset the counter to its initial state

-user value increment

-Centralized state management using Redux

-Clear separation of concerns using actions and reducers

-Simple and responsive user interface

Technology Stack

-React.js
-Redux
-JavaScript (ES6+)
-HTML5
-TailwindCSS
